About this model. XGBoost trained on 100,000 SDSS galaxies, using photometry only (no spectrum needed). On held-out data: accuracy 0.875, starburst precision 0.773, recall 0.704, F1 0.737. It misses about 3 in 10 real starbursts, so treat the output as an estimate, not a measurement. The labels come from spectra, and the model has been tested only on this one dataset.
